\section{Conclusion}
\label{sec:conclusion}

In this work, we presented \textbf{Dioptra-DINO}, an edge-compatible geometry-coupled architecture (27.51\,M parameters, 105.05\,MB weights) tailored for real-time monocular metric depth estimation on mobile robotics platforms. By coupling self-supervised DINOv2 representations with camera projective geometry via continuous Trivision ray encodings, Dioptra-DINO directly grounds visual transformer tokens in 3D optical space. The Angular Residual Attention (ARA) mechanism sharpens object silhouettes by penalizing divergent rays, decoupled scale consistency supervision enforces absolute metric calibration, and Multi-Scale 3D Virtual Normal Loss (VNL) regularizes planar architectural surfaces.

Evaluated on the continuous 200-frame held-out benchmark trajectory in TartanAir (\textit{abandonedfactory\slash Easy\slash P010}), Dioptra-DINO achieves \textbf{$0.0555$ AbsRel} ($5.55\%$ relative error), \textbf{$97.06\%$ $\delta_1 < 1.25$ threshold accuracy}, \textbf{$2.396$\,m RMSE}, and an absolute median metric scale ratio of \textbf{$1.0003$} (only $0.03\%$ scale error) without any test-time scale alignment, achieving substantially lower relative error than Depth Anything V2-Small ($0.0964$ AbsRel, $90.78\%$ $\delta_1$) and the camera-conditioned foundation model Metric3D ViT-Small ($0.3269$ AbsRel, $26.52\%$ $\delta_1$, $7.192$\,m RMSE) on this dynamic 6-DoF trajectory. Furthermore, dynamic pinhole crop augmentation enforces camera-intrinsic equivariance, preserving metric scale calibration within $\pm 3.2\%$ across the wide-angle operational range ($73.7^\circ \text{--} 100^\circ$) with $>95\%$ $\delta_1$ accuracy. While projective camera-ray conditioning successfully enforces optical equivariance across changing camera geometry, zero-shot transfer onto the real-world indoor benchmark (NYU Depth V2) demonstrates that unconstrained open-world metric scale priors necessitate multi-domain supervision beyond synthetic warehouse environments. Operating with steady-state FP32 forward inference at \textbf{$38.0$\,FPS} ($26.3$\,ms latency; $28.3$\,FPS / $35.3$\,ms end-to-end pipeline) on an Apple Silicon M3 GPU with peak working RAM under $210$\,MB, Dioptra-DINO demonstrates that coupling self-supervised visual representations with explicit projective geometric inductive biases enables robust, real-time metric depth estimation within an edge-compatible computational envelope.
