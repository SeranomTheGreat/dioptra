\begin{abstract}
Dense metric depth estimation from a single image is critical for autonomous robotics and spatial computing. However, recent foundation models rely on massive transformer backbones ($>300$\,M parameters), hindering edge deployment on memory-constrained hardware. We present \textbf{Dioptra}, an ultra-lightweight, geometry-aware architecture ($8.1$\,M parameters, $32.4$\,MB weights) that learns metric depth directly from scratch. Dioptra grounds visual tokens in physical 3D space through two camera-coupled mechanisms: (i)~\textit{Trivision Ray Positional Encoding}, which unprojects optical ray triplets per patch token using camera intrinsics with reflection symmetry tracking, and (ii)~\textit{Angular Residual Attention (ARA)}, an intrinsic geometric attention bias that penalizes off-axis angular distortion to sharpen surface discontinuities. Furthermore, we decouple global metric scale supervision from relative shape regularization via a log-median scale consistency loss. On a strict cross-environment split of the TartanAir dataset ($15$ training environments, $8,186$ held-out test frames across unseen 3D maps), Dioptra Stage~1 baseline achieves $0.3073$ Aligned AbsRel ($0.9293$ Metric AbsRel). Introducing dynamic pinhole crop augmentation prevents ray degeneracies and yields our headline Stage~2 performance of \textbf{$0.2901$ Aligned AbsRel} and \textbf{$0.6043$ Metric AbsRel} ($35.0\%$ error reduction), while multi-camera field-of-view sweeps ($50^\circ \text{--} 100^\circ$) demonstrate camera-intrinsic equivariance with up to \textbf{$-55.9\%$ error reduction} ($>2.2\times$ relative accuracy improvement) at telephoto angles. Across 40 uncompressed ground-truth held-out arrays, Stage~2 delivers robust zero-shot transfer ($0.7420$ Metric AbsRel; $0.2290$ in daylight industrial). Operating under $180$\,MB peak RAM with $52.8$\,ms steady-state FP32 inference on Apple Silicon ($\approx 18.9$\,FPS; $98.4$\,ms unoptimized baseline; $28.2$\,ms on NVIDIA T4; $334.9$\,ms full 3D mesh pipeline), Dioptra establishes that explicit geometric inductive biases achieve viable metric depth estimation within an edge-compatible computational envelope. Code is available at \url{https://github.com/SeranomTheGreat/dioptra}.
\end{abstract}
